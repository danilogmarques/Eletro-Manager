# Eletro Pronto — Materiais elétricos

Loja demonstrativa feita com Vite, React, TypeScript e Tailwind CSS.

## Executar

Na pasta deste projeto:

```sh
npm install
npm run dev
```

Para gerar a versão de produção:

```sh
npm run build
npm run preview
```

Para executar a suíte de testes:

```sh
npm test
```

O catálogo e os preços são ilustrativos. O checkout e a newsletter ainda não
estão conectados a serviços de pagamento, pedidos ou e-mail.
